# LemonADE: Agentic Document Extraction 

*In the past, I used Mint app (RIP) to categorize my expenses and observe my spending habits. Now that Mint is gone, I'm making this little project and by naming it lemonADE, I'm hinting at the Agentic Document Extraction (which is the core principle of the project) while also giving a new fresh name to replace Mint.*

This project aims to help me (and you!) budget better by showing monthly expenses by category, using bank/credit card statements.
